## 1. PRODUCT DEFINITION

### 1.1 Device Overview

**Product Name:** ProGuard™ Hybrid Access & Closure System

**Clinical Application:** Large-bore femoral arterial access for transcatheter cardiovascular procedures (TAVR, EVAR, Impella placement, complex PCI)

**Unique Value Proposition:** World's first device combining:
- Inside-out arterial puncture from intravascular position
- Transradial catheter delivery approach
- Prophylactic suture placement BEFORE large-bore arteriotomy dilation

### 1.2 Technical Components

#### A. Delivery Platform (Main Catheter Body)
| Component | Specification |
|-----------|---------------|
| Length | 120-150 cm |
| Outer Diameter | 6-7 French (2.0-2.3mm) |
| Material | Polyether Block Amide (PEBAX) with graded stiffness |
| Coating | Hydrophilic polymer |
| Markers | Radiopaque markers every 10cm |

#### B. Pentad-Needle Array (Core Innovation)
| Component | Specification |
|-----------|---------------|
| Central Port | 18-21 Gauge access needle with integrated 0.035" guidewire |
| Peripheral Ports | Four 23G-equivalent nitinol micro-needles (90° radial spacing) |
| Suture Material | 2-0 braided polyester |
| Suture Configuration | Two paired loops (Box stitch pattern) |
| Needle Extension | 5-12cm adjustable |

#### C. Needle Guide Mechanism
| Component | Specification |
|-----------|---------------|
| Size | 3 French |
| Material | Flexible polymer |
| Deflection Angles | 0°, 30°, 60°, 90° (indexed) |
| Actuation | Rotary-to-tension pull-wire system |

#### D. Sharp Recanalization Element (Needle Wire)
| Component | Specification |
|-----------|---------------|
| Diameter | 2 French (0.66mm) |
| Material | 316 Stainless steel |
| Length | 180 cm total, 35 cm working length |
| Tip Geometry | Multi-beveled penetration point |

### 1.3 Method of Use

**Phase 1: Navigation & Positioning**
1. Radial artery access (6Fr)
2. Catheter navigation through arterial system to common femoral artery
3. Fluoroscopic positioning confirmation
4. Anterior orientation verification (avoiding femoral vein/nerve)

**Phase 2: Inside-Out Puncture**
5. Peripheral suture needle deployment (4 nitinol needles)
6. Suture externalization through skin
7. Central access needle deployment
8. Guidewire capture and externalization

**Phase 3: Procedure**
9. Pentad catheter removal over central guidewire
10. Large-bore sheath placement (12-24Fr)
11. Primary intervention (TAVR, EVAR, etc.)

**Phase 4: Closure**
12. Sheath removal
13. Pre-positioned suture cinching (box-stitch closure)
14. Hemostasis confirmation

### 1.4 Materials

| Component | Material | Rationale |
|-----------|----------|-----------|
| Catheter Shaft | PEBAX (graded durometer) | Flexibility + torque transmission |
| Radiopaque Markers | Barium sulfate/tungsten | Fluoroscopic visualization |
| Needle Wire | 316 Stainless steel | Corrosion resistance, stiffness |
| Suture Needles | Nitinol (NiTi alloy) | Superelasticity, shape memory |
| Suture | 2-0 Braided polyester | High tensile strength |
| Handle | Medical-grade PA/ABS/PC | Ergonomic precision |

### 1.5 Key Differentiating Features

1. **Inside-Out Arterial Access** - Puncture originates from within artery lumen
2. **Transradial Delivery** - Device navigated from wrist to femoral artery
3. **Pentad Needle Array** - 5-port system (1 central + 4 peripheral)
4. **Prophylactic Suture Placement** - Closure sutures positioned BEFORE dilation
5. **Simultaneous Deployment** - All needles deploy in single actuation
6. **Integrated Access & Closure** - Single device provides both functions
