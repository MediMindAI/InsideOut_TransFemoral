## The PCT System - Your Path to Worldwide Protection {#pct-system}

### What is PCT?

The **Patent Cooperation Treaty (PCT)** is an international treaty with **157 contracting states** that allows you to file ONE international patent application that simultaneously seeks protection in multiple countries.

**Important:** PCT does NOT grant a "world patent" - no such thing exists. Instead, it:
- Gives you **"Patent Pending"** status in all 157 member countries
- Provides **30-31 months** to decide which countries to pursue
- Delays major costs until you have market validation
- Provides a professional **International Search Report** on your invention

### PCT Member Countries Include:

**Major Markets:**
- 🇺🇸 United States
- 🇪🇺 European Union (via EPO)
- 🇨🇳 China
- 🇯🇵 Japan
- 🇰🇷 South Korea
- 🇮🇳 India
- 🇧🇷 Brazil
- 🇦🇺 Australia
- 🇨🇦 Canada
- 🇬🇧 United Kingdom
- 🇬🇪 Georgia

**And 145+ more countries!**

### PHASE 3: INTERNATIONAL PHASE (Months 1-30)

#### Month 3-4: International Search Report (ISR)

**What Happens:**
- Your chosen ISA (EPO/USPTO) searches prior art
- Examiner reviews novelty and inventive step
- ISR issued with list of relevant prior art
- Written Opinion on patentability provided

**Your Actions:**
- [ ] Review ISR carefully
- [ ] Assess cited prior art
- [ ] Consider claim amendments if needed
- [ ] Discuss with patent attorney
- [ ] NO RESPONSE REQUIRED (but can file informal comments)

#### Month 16: Written Opinion

**What Happens:**
- Detailed opinion on patentability
- Indicates if claims are novel, inventive, industrially applicable

**Your Actions:**
- [ ] Review Written Opinion
- [ ] Plan strategy for national phase
- [ ] Consider filing amendments

#### Month 18: International Publication

**What Happens:**
- Application published on WIPO PATENTSCOPE
- Becomes publicly available
- **"PATENT PENDING" officially public**
- Publication number assigned

**Your Actions:**
- [ ] Verify publication details are correct
- [ ] Begin marketing with "Patent Pending" status
- [ ] Monitor for competitor applications

#### Month 19-22: Optional Preliminary Examination

**What You Can Do:**
- Request International Preliminary Examination (Chapter II)
- Get second opinion on patentability
- Opportunity to amend claims before national phase
- **Cost:** Additional ~600-2,000 USD

**Recommended if:**
- ISR was negative
- You want to strengthen application before national phase
- You need more certainty for investors

#### Months 22-30: National Phase Preparation

**Critical Planning Period:**

- [ ] Finalize list of countries for national phase
- [ ] Budget for national phase costs
- [ ] Arrange translations
- [ ] Engage local patent attorneys in target countries
- [ ] Prepare response strategies for each office

   - Priority claims (if any)
   - ISA selection

2. **Description (Specification)**
   - Technical field
   - Background/prior art
   - Summary of invention
   - Detailed description
   - Best mode of implementation
   - Industrial applicability
   - **Format:** Clear, complete, enables skilled person to reproduce

3. **Claims**
   - Independent claims (what you protect)
   - Dependent claims (specific features)
   - **Format:** Clear, concise, supported by description

4. **Abstract**
   - Brief summary (150 words max)
   - Technical problem and solution
   - Main use

5. **Drawings** (if applicable)
   - Technical drawings, schematics, flowcharts
   - Properly numbered and referenced
   - Black and white, suitable for reproduction

**Optional Documents:**

6. **Priority Document** (if claiming earlier filing)
   - Certified copy from original office
   - Can be retrieved via DAS (Digital Access Service)

7. **Sequence Listing** (for biotech)
   - WIPO Standard ST.26 XML format

8. **Power of Attorney**
   - If using patent attorney
   - For Sakpatent: required within 2 months if not filed with application

### New Option: Validate European Patents in Georgia

**Effective: January 15, 2024**

Georgia is now the **5th EPO Validation State** (joining Morocco, Moldova, Tunisia, Cambodia).

### What This Means

You can now:
1. File a European Patent Application (directly or via Euro-PCT)
2. Designate Georgia during filing
3. After EPO grants patent, validate it in Georgia
4. Get patent protection in Georgia through the European system

### Requirements for Georgia Validation

| Requirement | Details |
|-------------|---------|
| **Designation Fee** | €200 (pay within 6 months of EP publication) |
| **Validation Fee** | Paid to Sakpatent after grant |
| **Translation** | Full Georgian translation of specification |
| **Deadline** | 3 months from EP grant publication |

### When to Use European Validation vs. Direct Georgia Filing

**Use EP Validation if:**
- You're filing in Europe anyway
- You want unified examination process
- You prefer EPO examination quality
- Budget allows for EPO fees

**Use Direct Georgia Filing if:**
- You only want Georgia protection
- Budget is limited
- You want faster processing
- You qualify for Georgian discounts

### Recommended Hybrid Strategy

1. **File PCT through Sakpatent** (for worldwide pending status)
2. **Enter national phase at EPO** (for European protection)
3. **Validate EPO patent in Georgia** (extends European protection to Georgia)
4. **Also enter Georgia national phase directly** (backup/faster option)

### Cost-Saving Strategies

1. **Maximize Georgian Discounts**
   - If you qualify for 70-90% reduction, save thousands
   - File as individual inventor if possible
   - Use e-filing for additional discounts

2. **Strategic Country Selection**
   - File in fewer countries initially
   - Add countries later if needed
   - Focus on markets with actual commercial potential

3. **Use Patent Prosecution Highway (PPH)**
   - Accelerates examination in partner countries
   - Uses work from first office
   - Reduces prosecution costs

4. **Provisional + PCT Strategy (Alternative)**
   - File US provisional first ($320)
   - File PCT within 12 months
   - Gain extra year to prepare

5. **Delay Non-Critical Countries**
   - Enter critical markets at month 30
   - Some countries have later deadlines
   - Spread costs over time

### Medical Device-Specific Tips

1. **Comprehensive Claims**
   - Device claims (the physical structure)
   - Method claims (how to use it)
   - Manufacturing claims (how to make it)
   - System claims (device + components)

2. **Design Protection**
   - Consider industrial design registration
   - Protects ornamental appearance
   - Complements patent protection

3. **Continuation Strategy**
   - File continuation applications
   - Capture improvements and variations
   - Build patent family over time

4. **Freedom to Operate**
   - Search existing patents
   - Ensure you don't infringe others
   - Consider design-arounds if needed

5. **Regulatory Alignment**
   - Patent filing can parallel regulatory approval
   - CE marking (Europe) separate from patents
   - FDA approval (US) separate from patents
   - Patent protection ≠ regulatory approval
